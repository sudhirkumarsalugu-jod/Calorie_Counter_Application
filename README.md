# Calorie_Counter_Application
Calorie counter application helps you to find your daily calorie intake and suggests foods and workouts to achieve your goal weight.  It has Inbuild exceptional days feature which helps the people who don't eat non-veg on some particular dates. It also has a BMOI calculator which helps user to find their BMI. Also It helps user to extract grocery list from the AI generated diet plan to save time and efforts. I also Included swap meal feature where a user can change a meal from a existing plan and get a substitute of that meal with ssame nutrients with the helpof AI.
